# 2026-10-22

## 构建清单新增 branch 字段

`config/build-list.json` 现在支持 `branch` 指定构建分支，解决源码 Dockerfile 不在默认分支的情况。

- 矩阵字段 `source_ref` 更名为主字段 `branch`，解析表达式为 `(.branch // .source_ref // "")`：`branch` 优先、回落到旧字段，已有配置无需改动。
- `actions/checkout` 的 `ref`、运行摘要的「源码分支」都改用 `matrix.branch`；为空时 checkout 自动检出默认分支。
- `branch` 除分支名外也可填 tag 或 commit（都是交给 `ref`）。
- README 字段表、示例已同步。
- 校验：jq 库实测五种输入（只写 branch / 只写 source_ref / 两者都写 / 都不写 / 空串），优先级与默认值均正确。
